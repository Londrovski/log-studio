Settings

The app reads its templates from the GitLab assets repo, so a change pushed there shows up here without redeploying. It needs a read-only access token to do that, and tokens expire — usually after a year.

Making a token that works

In GitLab, open log-studio-assets → Settings → Access tokens, and create a project access token — not a personal one. A personal token would hand out everything your account can see, and this one is published in the app where anyone can read it.

  • Role: Reporter
  • Scopes: read_api, read_repository, read_registry
  • Expiry: as long as GitLab allows

Saving it here fixes it on this machine only. To fix it for everyone, put it in config.json in the log-studio repo, under gitlab.token, and push — the site rebuilds itself.
