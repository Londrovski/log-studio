TBRe Log Studio — GitLab streaming test

This page is served from GitHub Pages. It tries every way a browser could read the app's templates out of the private GitLab repo tbre-ai/software-tools/log-studio-assets, and reports which ones a real browser allows. That decides how the launcher is built.

Only used in your browser, stored locally. Leave blank to test the signed-in-session routes only.

What each route means

Raw file, signed-in sessionThe simplest: the launcher fetches the template file directly, relying on your GitLab login cookie.
API with your loginSame, through GitLab's API instead of the raw file path.
API with an access tokenYou paste a token once and the launcher remembers it. Works without cookies.
Script tagLoading code from GitLab the way a page loads a script. Bypasses the usual cross-site rules, but GitLab may refuse to serve it as code.
Image tagThe control: this is how my earlier preview pulled photos out of GitLab, and it should pass.
GitHub rawThe other control: a public source, which should always work.
